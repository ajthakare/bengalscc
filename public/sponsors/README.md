## Logo Requirements
- Format: PNG with transparent background (preferred)
- Recommended size: 400px wide (height auto)
- High resolution for clarity
- Consistent aspect ratios

## Adding New Logos
1. Add logo file to this directory
2. Update /src/config.ts SPONSORS object with sponsor details
3. Reference logo path as: /sponsors/filename.png
